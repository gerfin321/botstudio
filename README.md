# gfn bots — сайт для GitHub Pages

Статичний односторінковий сайт студії розробки Telegram-ботів і Telegram Mini Apps. Не потребує збірки, сервера або npm-залежностей.

## Локальний запуск

Сайт можна відкрити подвійним кліком по `index.html`. Для коректної перевірки всіх сценаріїв зручніше запустити простий локальний сервер, наприклад:

```powershell
py -m http.server 8000
```

Після цього відкрийте `http://localhost:8000` у браузері.

## Публікація через GitHub Pages

1. Завантажте ці файли у корінь репозиторію GitHub.
2. Відкрийте **Settings → Pages** у репозиторії.
3. У блоці **Build and deployment** виберіть **Deploy from a branch**.
4. Вкажіть гілку `main` (або потрібну гілку) та папку `/(root)`.
5. Натисніть **Save**. GitHub надасть посилання на опублікований сайт.

## Що змінити перед публікацією

### Telegram username

На початку [script.js](script.js) змініть значення:

```js
const TELEGRAM_USERNAME = "gerfin228";
```

Посилання та нік у блоці контактів оновляться автоматично.

### Назва студії

Назва `gfn bots` вказана в `index.html`: у `<title>`, Open Graph-метаданих, логотипі header і footer. Замініть її на свою назву в цих місцях.

### Ціни калькулятора

Усі ціни зберігаються в одному об’єкті `services` у [script.js](script.js). Наприклад, щоб змінити базову ціну Telegram-бота, відредагуйте:

```js
bot: {
  basePrice: 500,
  // ...
}
```

Ціни додаткових функцій знаходяться в `options`, а ціни та ліміти лічильників — у `quantities`. Інтерфейс, підсумок і деталізація автоматично використовують ці значення.

## Файли

- `index.html` — семантична структура, контент і SEO-метадані.
- `styles.css` — адаптивний технічний дизайн без зовнішніх залежностей.
- `script.js` — конфігурація цін, калькулятор, навігація та невеликі анімації.
